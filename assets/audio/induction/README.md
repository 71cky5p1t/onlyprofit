# Induction voice

One clip per chapter, named by chapter id: `welcome.mp3`, `goal.mp3`, `saboteurs.mp3`, `inherit.mp3`, `policy.mp3`, `overtime.mp3`, `stamp.mp3`, `cover.mp3`, `ceo.mp3`, `board.mp3`, `approved.mp3`, `endgame.mp3`, `signoff.mp3` (`vo-01-welcome.mp3` style also works). Lines are in `src/explainer/00-lessons.js`. A clip sets its chapter's length, and the music ducks about 7 dB while it plays.
